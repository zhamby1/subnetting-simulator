Subnetting Basics

Think of an IP address like a street address. The network portion identifies the neighborhood; the host portion identifies a specific house.

Example: For 192.168.1.25/24, the first 24 bits describe the network. In this beginner example, that means 192.168.1 identifies the network and 25 identifies the host.

IP address

Identifies an interface on an IP network. Example: 192.168.1.25.

Subnet mask

Separates the network bits from the host bits. A /24 uses 255.255.255.0.

Network address

The first address in the subnet. It identifies the subnet itself and is not assigned to a normal host.

Broadcast address

The last address in a traditional IPv4 subnet. It can address all hosts on that subnet and is not assigned to a normal host.

Usable host range

The addresses between the network and broadcast addresses.

Default gateway

Usually a router interface used to reach destinations outside the local subnet.

Why /24?

IPv4 addresses contain 32 bits. CIDR notation tells us how many are network bits. /24 means 24 network bits and 8 host bits.

11111111 . 11111111 . 11111111 . 00000000
255      . 255      . 255      . 0

A /24 has 256 total addresses. In a normal subnet, 254 are usable host addresses because the network and broadcast addresses are reserved.

Quick trick: Hosts = 2host bits − 2. For /26, there are 32 − 26 = 6 host bits. 26 = 64 total addresses, so 62 usable hosts.

How to Subnet: Step by Step

Subnetting means taking one IP network and dividing it into smaller networks. The key is learning to find four things: the network address, broadcast address, first usable host, and last usable host.

Start with this question: What does the prefix tell us? IPv4 has 32 bits. In /26, 26 bits describe the network and 6 bits remain for hosts.

Step 1 — Find the subnet mask

A CIDR prefix is another way of writing the subnet mask. Each full group of 8 network bits becomes 255. A partial group is created by adding binary place values: 128, 64, 32, 16, 8, 4, 2, 1.

/26 = 11111111 . 11111111 . 11111111 . 11000000
255 . 255 . 255 . 192

So /26 = 255.255.255.192.

Step 2 — Find the block size

Look at the interesting octet—the octet where the mask is neither 255 nor 0. Subtract it from 256.

/26 example: 256 − 192 = 64. Therefore the subnet boundaries in the last octet are 0, 64, 128, 192.

Step 3 — Locate the IP address

Suppose the host is 192.168.1.100/26. The number 100 falls between the subnet boundaries 64 and 127. Therefore its network is 192.168.1.64/26.

Step 4 — Find network and broadcast

The first address of the block is the network address. The address immediately before the next subnet begins is the broadcast address. For this example, the next subnet begins at .128, so the broadcast is .127.

Step 5 — Find usable hosts

Traditionally, hosts use the addresses between network and broadcast. Therefore 192.168.1.64/26 has usable addresses 192.168.1.65 through 192.168.1.126.

Hosts versus subnets

Every bit moved from the host portion into the network portion creates more subnets but leaves fewer addresses inside each subnet.

/24 → /25: 2 subnets, 128 addresses each.
/24 → /26: 4 subnets, 64 addresses each.
/24 → /27: 8 subnets, 32 addresses each.

Pattern: Each time the prefix increases by 1, the number of equal-sized subnets doubles and the size of each subnet is cut in half.

The host formula

Calculate host bits with 32 − prefix. Then calculate total addresses with 2host bits.

For /27:
32 − 27 = 5 host bits
25 = 32 total addresses
32 − 2 = 30 traditional usable hosts

The “−2” reserves the network and broadcast addresses in conventional IPv4 LAN subnetting.

Worked Example: 10.10.20.77/28

1. /28 mask = 255.255.255.240.
2. Block size = 256 − 240 = 16.
3. Boundaries are 0, 16, 32, 48, 64, 80, 96…
4. 77 is in the 64–79 block.
5. Network = 10.10.20.64.
6. Broadcast = 10.10.20.79.
7. Usable range = 10.10.20.65–10.10.20.78.
8. /28 has 4 host bits → 16 total addresses → 14 traditional usable hosts.

Student strategy: On paper, write the block size first. Then count subnet boundaries until you pass the host IP. The boundary immediately before the host is the network address; one less than the next boundary is the broadcast.

Why subnet in a real network?

Subnetting is not only a math exercise. Administrators use it to organize address space and create separate IP networks. For example, an organization might place office computers in one subnet, student devices in another, and servers in another. Routers or Layer 3 switches can then move traffic between those networks according to the network design and security rules.

Important distinction: A subnet is a Layer 3 IP concept. A VLAN is a Layer 2 segmentation concept. They are commonly paired—often one IP subnet per VLAN—but they are not the same thing.
