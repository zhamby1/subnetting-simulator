IP Addressing Without the Heavy Math

For this activity, students do not need to become subnetting engineers. The goal is to understand what the subnet mask does, recognize common IPv4 settings, and troubleshoot a computer that cannot communicate.

The one sentence to remember: The subnet mask helps a computer decide which IP addresses are local and which destinations need to be sent to the default gateway.

A+ Networking Essentials

IP Address

The address assigned to a network interface, such as 192.168.1.25.

Subnet Mask

Defines which part represents the network. A very common lab example is 255.255.255.0.

Default Gateway

The router address a PC uses to reach other networks, often something like 192.168.1.1.

Example configuration
IP: 192.168.1.25
Mask: 255.255.255.0
Gateway: 192.168.1.1

The PC and gateway are both in the 192.168.1.x network when using this /24 mask.

DHCP, Static, and APIPA

TermWhat a student should recognize
DHCPAutomatically supplies network settings such as IP address, mask, gateway, and usually DNS information.
Static IPNetwork settings are entered manually. Incorrect values can cause connectivity problems.
APIPAA Windows host may self-assign a 169.254.x.x address when it cannot obtain an IPv4 address from DHCP. This is an important troubleshooting clue.

Private IPv4 addresses

Recognize these ranges as addresses commonly used inside private networks:

10.0.0.0 – 10.255.255.255
172.16.0.0 – 172.31.255.255
192.168.0.0 – 192.168.255.255

Subnet Masks — The A+ Friendly Version

You mainly need to understand the mask's job. Start with 255.255.255.0, also written /24.

Look at the IP.
PC A = 192.168.10.25
Look at the mask.
255.255.255.0 means the first three numbers identify the network in this simple example.
Compare another address.
PC B = 192.168.10.80. The first three numbers match, so both are in the same 192.168.10.x /24 network.
Compare a different network.
192.168.20.80 does not match the 192.168.10.x network. Traffic between them normally needs a router.
Exam-style thought process: If a workstation has 192.168.1.50 / 255.255.255.0 but its gateway is 192.168.2.1, the gateway is not in the workstation's local /24. That configuration should make you suspicious.

What does /24 mean?

/24 = 255.255.255.0. The “24” means 24 bits are used for the network prefix. For this beginner activity, recognizing the equivalence is more useful than performing binary conversions.

A+ Troubleshooting Clues

You see…Think about…
169.254.23.8APIPA. Check whether DHCP is reachable/working and check the physical/network connection.
192.168.1.25 /24, gateway 192.168.2.1Gateway appears to be on a different /24 network.
No link light / disconnected cableStart with the physical connection before changing IP settings.
Valid local IP but websites fail by nameDNS may be involved; do not assume every connectivity symptom is a subnet problem.
Duplicate IP warningTwo devices may have been assigned the same IPv4 address.
Good troubleshooting order: physical connection → IP configuration → local connectivity/gateway → name resolution and outside connectivity.
