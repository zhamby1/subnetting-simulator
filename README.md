# Subnet Lab
A beginner-friendly subnetting simulation website for students.

## Activities
- Intro lesson and terminology
- CIDR/subnet cheat sheet
- Interactive IPv4 subnet calculator
- Same-network connectivity simulator
- Small-office configuration challenge
- Five-question knowledge check

## Run locally
Open `index.html` in a web browser. No server or dependencies are required.

## GitHub Pages
Upload `index.html` to a GitHub repository, then enable GitHub Pages for the repository's main branch/root folder.
