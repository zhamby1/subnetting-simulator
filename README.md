# Subnet Lab
A beginner-friendly subnetting simulation website for students.

## Expanded learning content
- Detailed step-by-step subnetting lesson
- CIDR and subnet-mask explanation
- Block-size / magic-number method
- Host-bit and usable-host calculations
- Worked /26 and /28 examples
- Real-world reasons for subnetting and VLAN/subnet distinction
- Embedded beginner videos from Practical Networking
- Links to additional Practical Networking and Professor Messer lessons

## Interactive activities
- CIDR/subnet cheat sheet
- Interactive IPv4 subnet calculator
- Same-network connectivity simulator
- Small-office configuration challenge
- Five-question knowledge check

## Run locally
Open `index.html` in a web browser. No server or dependencies are required. An internet connection is required for embedded external videos.

## GitHub Pages
Upload `index.html` to a GitHub repository, then enable GitHub Pages for the repository's main branch/root folder.
